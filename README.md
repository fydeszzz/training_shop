# HOTPOTGO — Self-Service Hot Pot Shopping Website

A Java-based e-commerce web application simulating a self-service hot pot ordering platform, built as a training capstone project.

---
## 🛒 Features

**Member Center**
- Edit and update personal profile information
- View past order history

**Product Pages**
- Search for products by keyword or category
- Individual product detail display page

**Shopping Cart**
- Add, adjust quantity, or remove items in real time
- Direct links to individual product pages from the cart

**Order Page**
- Review items currently in the shopping cart
- Confirm payment method and modify shipping/delivery information

**Admin Backend**
- Member management (view, edit, manage accounts)
- Product management (add, update, remove listings)
- Order management (track and process orders)
